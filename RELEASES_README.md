# 🎵 Melo

**Бесплатный музыкальный плеер для Android** — поиск, бесконечная волна и плейлисты из открытых источников. Без рекламы, без регистрации, без сбора данных.

Это репозиторий **готовых сборок (релизов)**. Исходный код — в основном репозитории.

---

## ⬇️ Установка

1. Открой вкладку **[Releases](../../releases)**.
2. Скачай свежий `app-release.apk` из последнего релиза.
3. Открой файл на телефоне и разреши установку из неизвестных источников.
4. Готово — запускай и слушай.

> Обновление: просто скачай и поставь новый APK поверх — данные (избранное, плейлисты) сохранятся.

**Требования:** Android 8.0+ · 64-битное устройство (arm64).

---

## ✨ Возможности

- 🔎 **Поиск** треков и исполнителей по нескольким источникам сразу
- 🌊 **Sea** — бесконечная персональная волна, подстраивается под твой вкус
- ❤️ **Избранное** и **плейлисты** со своими обложками
- 📥 **Скачивание** треков и офлайн-воспроизведение
- 📁 **Импорт плейлистов** — из YouTube Music, SoundCloud и из папки на устройстве
- 📖 **Синхронный текст** песни (LRC) + караоке-подсветка по словам
- 🎚 **Эквалайзер**, усиление и реверберация
- ⏩ **Скорость и тон** — slowed / sped up версии с сохранением
- 🎧 **Фоновое воспроизведение**, управление с наушников и экрана блокировки
- 🎨 Современный дизайн Material You (системные цвета)

---

## 🔒 Приватность

Melo не собирает и не передаёт персональные данные. Избранное, плейлисты и история хранятся только на твоём устройстве. Нет аккаунтов, аналитики и рекламы.

---

## ⚠️ Дисклеймер

Melo — плеер-агрегатор. Он не размещает и не хранит аудио на серверах: музыка воспроизводится из открытых публичных источников через соединение самого устройства. Все права на контент принадлежат их правообладателям. Приложение распространяется «как есть», для личного некоммерческого использования.
